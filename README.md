# Daily Routine Hybrid

A lightweight Android reminder app for meals, workouts, water, sleep, meditation, and custom routines.

## What is included
- Kotlin + XML Android app
- Reminder list with add / edit / delete
- Daily and interval reminders
- Notification actions: **Done** and **Snooze**
- Boot restore support
- Simple home dashboard with today's progress

## Build notes
Open the project in Android Studio and let Gradle sync.  
The app is configured for:
- **minSdk** 26
- **compileSdk** 34
- Kotlin + Material Components

## Default routine ideas
- Breakfast
- Lunch
- Dinner
- Morning workout
- Drink water
- Stand and stretch
- Bedtime
- Meditation
