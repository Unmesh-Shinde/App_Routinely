Overview

What this app does

Daily Routine Hybrid, presented in the report as Routinely, is an Android wellness companion. It combines daily reminder management with health tracking, meal planning, workout planning, progress scoring, profile metrics, and shareable wellness reporting.

Reminders

Routine reminders and notifications

Reminder functionality is the foundation of the app. It helps users turn health goals and daily responsibilities into scheduled actions.

Reminder typePurposeDefault user message
Meal Time 🍽️Breakfast, lunch, dinner, snack, or custom food reminder.Eat healthy and mindfully.
Exercise 💪Workout or movement sessions.Time to get moving.
Hydration 💧Regular water intake.Stay hydrated.
Sleep 😴Bedtime and wind-down prompts.Get restful sleep.

Weekend Tasks 🏡Weekend goals and chores.Remember weekend goals.
Monthly Tasks 📅Monthly reviews or recurring monthly habits.Review monthly progress.
Custom ⏰Anything the user wants to schedule.Scheduled activity reminder.
Scheduling options

Reminders can run at a specific hour/minute, repeat on selected days, repeat monthly on a day of month, or run as interval reminders every configured number of minutes.

Notification actions

Notifications include Done and Snooze actions. Done records progress; Snooze delays the reminder without requiring users to open the app.

Boot restore

A boot receiver restores enabled reminders after a device restart, so reminders continue working after reboot or quick boot events.

Hidden plan reminders

Meals and exercises can sync into the reminder system as hidden reminders, keeping plan-based alerts working without cluttering the main reminder list.

Planning

Diet plan and workout plan

Calendar-first planning

Both meals and exercises are stored against specific dates, allowing the user to plan different routines for different days.

Meal entries

Each meal can contain a name, description, time, meal type such as Breakfast/Lunch/Dinner/Snack, calorie value, and reminder toggle.

Meal templates

Users can create, rename, duplicate, delete, and apply meal templates. Template durations include weekly, 10 days, fortnight/bi-weekly, and monthly ranges.

Exercise entries

Each exercise can include name, sets, reps or duration, target area, intensity from 0 to 100, time, reminder toggle, MET estimate, and MET source.

Workout templates

Workout templates can be built from existing date ranges and applied to future ranges with overlap checks to avoid accidental conflicts.

Progress connection

Completed meals and exercises contribute to nutrition and workout parts of the wellness score, making planning directly visible in daily progress.

Implementation detail: The planning system is managed by PlanManager and stored with Gson in SharedPreferences. It supports date-keyed meal and exercise lists plus applied template ranges.

Health tracking

Health data and integrations

The app combines local wellness data with Android health integrations so users can view meaningful daily and historical trends.

🔗

Health Connect

Reads steps, sleep, active calories, total calories, basal metabolic rate, distance, exercise sessions, weight, historical data, and background health data when permissions allow.

💚

Google Fit Heart Points

Uses Google Sign-In fitness scopes to read raw and aggregate Heart Points, including daily buckets for history.

📱

Fitness app scanner

Detects installed fitness apps such as Google Fit, Samsung Health, Fitbit, Garmin, Xiaomi, Zepp, NoiseFit, boAt, Huawei Health, Withings, Suunto, Polar, and more.

📊

Historical storage

Keeps historical values for steps, sleep, calories, heart points, and weight. Health sync history is designed around a 180-day window.

Scoring and insights

Wellness score and profile metrics

The app turns several daily signals into a score out of 100, while also calculating personal health metrics from the user profile.

Default score weighting

Weights can be customized by the user in the score customization screen.

Sleep
Workout
Nutrition

How scoring behaves

If a data area has no logged/planned data, the active factors are rescaled instead of unfairly punishing the user. The final score is clamped between 0 and 100.

Sleep progressWorkout completionNutrition completionStep goal progress

Profile calculations

Profile metrics include BMI category, BMR using Mifflin-St Jeor style formulas, ideal weight, and ideal daily calories rounded to the nearest 50.

Trend insight

The wellness engine compares current-week and previous-week step totals to generate friendly weekly movement insights.

Why this matters

Instead of only listing raw numbers, the app translates routine completion and health data into motivation: “keep moving,” “good start,” “great job,” and similar dashboard feedback.

Reports and background services

Reports, widget, sync, and permissions

📄

180-day wellness PDF report

The in-app report generator creates a shareable PDF with daily rows for steps, intake, burned calories, net calories, sleep, weight, BMI, notes, and summary totals.

🧩

Wellness widget

A home screen widget displays wellness information and supports quick actions such as adding water.

🔄

Background health sync

A WorkManager worker syncs health data in the background and supports modes such as all data, steps-only, sleep-only, and history-focused sync.

🔐

Permission flow

The app requests notifications, exact alarms, Health Connect permissions, and Google Fit access when needed. It checks permissions before reading data.

User journey

How a user would experience the app

Sign up and set profile

The user starts with basic onboarding, then fills in profile data such as name, age, height, weight, and gender for personalized metrics.

Connect health sources

The app scans known fitness apps, requests Health Connect access, and can request Google Fit Heart Points permission.

Plan the day

The user adds meals, workouts, water goals, sleep reminders, meditation prompts, to-dos, or custom routines.

Receive reminders

Scheduled notifications appear at the right time. The user can mark them Done or Snooze them directly from the notification.

Review progress

The dashboard and detail screens show health data, completion progress, score, and weekly/monthly walking trends.

Export wellness history

When needed, the user can generate a 180-day wellness report PDF for review, sharing, or personal record keeping.
